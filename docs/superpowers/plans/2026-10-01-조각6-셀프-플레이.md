# 조각 6 — 셀프 플레이 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 파이터 망을 세우고 보스와 번갈아 학습해, 봇의 빈틈만 파는 보스가 아니라 배우는 상대를 이기는 보스를 만든다.

**Spec:** `docs/superpowers/specs/2026-10-01-조각6-셀프-플레이-design.md`

## Global Constraints
- 게임 · 규칙 조종기 판 그대로(골든). 파이터 망 코드는 순수 규칙 층(테스트가 링크) — 게임은 안 쓴다.
- `tools/build.sh check` 초록(파이썬 포함).

## Review Focus
- 파이터 칸의 엣지가 첫 틱에만 · 히트스톱 없음(일꾼은 틱만 민다).
- 파이터 관측의 보스 칸이 정말 12틱 앞인가.
- 배우는 쪽이 아닌 망의 결정이 steps.bin 에 섞이지 않는가.
- 파이터 보상의 부호 · 시간 초과.
- 상대 묶음의 고르기가 결정론인가 · 학습 시드와 평가 시드가 안 겹치는가.

### Task 1: 파이터 칸 · 관측 · 망 조종기 (C# 순수)
- `FighterActions` · `FighterObservation` · `FighterNetDriver`(Next(sim) → InputFrame · 기록) + 테스트.

### Task 2: 일꾼의 배우는 쪽 · 상대 묶음
- `RolloutRun` 일반화(`--learner` · `--opponents`) · 파이터 보상 · 테스트.

### Task 3: 셀프 플레이 · 평가 · 첫 실행
- `ml/rl/selfplay.py` · `ml/rl/evalboss.py` · `train.json` 의 `selfplay` · `fighter_reward` · `tools/build.sh selfplay|evalboss`. 실행해 결과를 PR 에.
