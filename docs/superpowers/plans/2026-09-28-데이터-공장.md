# 데이터 공장 + PlayerFeatures — 패턴을 고르는 망 2번 PR 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 봇 함대로 망의 학습 데이터를 짓는 .NET 콘솔(`tools/factory`)과, 공장과 게임이 같이 쓰는 입력 벡터(`PlayerFeatures`)를 세운다 — 같은 시드면 스레드 수와 무관하게 같은 파일이고, 원본에 겨냥 표가 보여야 한다.

**Architecture:**
- 규칙 층에 `PlayerFeatures`(기록 → 19칸)와 `overfit/core/DataDigest`(데이터 다섯 JSON 의 sha256 — 공장의 매니페스트와 4번 PR 의 오래된 망 경고가 같이 쓴다).
- `tools/factory/` 의 순수 파일 넷 — `InstanceTracker`(사례 가르기 · 라벨) · `BotRun`(봇 한 대의 흐름) · `FactoryBatch`(묶음 병렬 · 봇 번호 순서로 내기) · `SampleCsv`(행 서식). 테스트 프로젝트도 링크한다. `Program.cs` 는 인자 · 파일 · 매니페스트 · 로그 싱크뿐이다.
- 공장 csproj 는 솔루션(`overfit/Overfit.sln`)에 든다 — `check` 의 포맷 · 빌드 단계가 그대로 공장을 덮는다(CLAUDE.md §0: 검증하는 곳이 늘어도 그 명령 하나).
- 겨냥 표(설계 의도)는 `fleet.json` 의 `targeting` 이다 — 공장 · 학습 평가 · 검증이 같은 표를 읽는다.

**Tech Stack:** C# 12 (.NET 8) · xunit v3 + Shouldly · bash(`tools/build.sh`)

**Spec:** `docs/superpowers/specs/2026-09-28-패턴-고르는-망-design.md` — §4 전부 · §5.6 의 `data_digest` · §8(결정론) · §9 의 2번 줄 · §10 의 2번 줄.

## Global Constraints

- 공장은 게임과 **같은 자리에서** 판을 세운다 — 1단계는 `StageRoster.Setup`, 2단계는 명부만 `StageRoster.For` 에서 읽고 고르기는 `UniformPicker` 로 고정한다(스펙 §4.2).
- 입력은 **시도를 시작할 때 한 번** `PlayerFeatures.From(그때까지의 기록)` — 게임의 고르기가 서는 그 자리 · 그 재료다.
- 라벨 = 사례에 `Hit` · `GuardBroken` · `Grabbed` 가 하나라도 있나. 끝나지 않고 안 맞은 사례는 버린다(스펙 §4.3).
- 수는 불변 문화 · 왕복 서식(`"R"`). 봇 번호 순서로 쓴다 — 스레드 수와 무관하게 바이트까지 같다(스펙 §4.5).
- 공장은 스레드를 띄우기 전에 `Log.Level = Warn` 을 한 번 정하고 제 싱크(잠금 · 줄 세기)를 꽂는다. `[E]` 가 하나라도 나면 실패로 끝난다. 끝에 `[factory][M] factory=done`.
- 리플레이 골든은 안 움직인다. 링크된 규칙 파일을 바꾼 커밋마다 블록을 적는다.

## Review Focus

1. **같은 패턴이 연달아 뽑힌다** — uniform 은 같은 칸을 이어 뽑는다. 사례는 `CurrentPattern` 의 null → id 로 가르므로 패턴 사이의 간격이 둘을 가른다 — Task 3 의 합성 테스트.
2. **보스의 탈진으로 끊긴 사례** — 패턴이 null 로 돌아가므로 끝난 사례다(파이터가 이긴 교환 · 라벨 0). 판이 그 사례 도중에 끝난 것과 섞으면 안 된다 — Task 3.
3. **1단계를 끝내 못 이긴 봇** — 2단계 표본이 없고 수만 센다. `bots.csv` 에 `reached_stage2=false` — Task 4.
4. **메모리** — 봇 10만 대의 표본을 한꺼번에 들면 GB 단위다. 묶음(1,000 대)으로 돌리고 묶음마다 쓴다 — Task 5.
5. **규칙 층의 `[E]`** — 공장이 그 줄을 삼키면 망이 규칙 위반의 판을 배운다. 싱크가 세고 실패로 끝낸다 — Task 6.

**Files:** Create `tools/factory/InstanceTracker.cs` · 테스트 csproj 링크 · Test `tests/Overfit.Rules.Tests/Factory/InstanceTrackerTests.cs`
