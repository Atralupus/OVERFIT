# 플레이어 — 보스전 재설계 2/4 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이 PR 이 하는 일은 셋이다. 입력은 사람과 봇이 같은 계약(`InputFrame`)으로 낸다.
- 차지를 걷고 2연격(J)을 세운다.
- 가드(↓ · S 를 누르고 있는 동안)와 패리(K · 0.333초 커밋 · 앞 0.133초 창)를 다시 가른다.
- 파이터의 칼이 그림의 흰 궤적(`hitboxes.json`)으로, 판정 창 동안 맞게 한다.

**Architecture:**
- 규칙 층(`Fighter` · `BattleSim` · `HitResolver` · `BotPolicy`)이 바뀌고, 뷰(`Battle` · `FighterView` · `ShotRunner`)는 그 결과를 그린다.
- 칼질은 `fighters.json` 의 `combo` 목록에 적는다. 한 칸이 칼질 하나다: 그림의 장 · 시간 · 피해 · 칼의 판정 모양 id.
- `BattleSim` 은 판을 세울 때 판정 모양을 찾아 두고, 칼을 창 동안 살린다.
- 맨 먼저 회피의 공을 돌리는 일(`DodgeCredit`)을 `BattleSim` 에서 떼어 낸다. 1번 PR 이 넘긴 첫 일이다.

**Tech Stack:** Godot 4.7.2 mono · C# 12 (.NET 8) · xunit v3 + Shouldly · Python 3(도구)

**Spec:**

## 이 계획이 정한 것 — 스펙이 말하지 않은 자리

리뷰어는 이것을 스펙과 같은 무게로 읽는다. 틀렸으면 여기를 고친다.

1. **가드를 드는 값은 없다.**
   - 스펙 §5.2 는 칩(25%)과 피해에 비례하는 스태미나(× 1.8)만 적는다. 다크소울처럼 방패를 드는 것은 공짜고, 막는 것이 값이다.
   - v0.6.0 에서 K 를 누를 때 들던 15 는 패리와 가드가 한 행동이던 때의 패리 값이다.
2. **가드는 레벨로 산다.**
   - 이 셋이 함께 참인 틱이 가드다: ↓ 를 누르고 있다 · 땅에 서 있다 · 커밋된 행동(대시 · 칼질 · 패리)이 없다.
   - 그래서 칼질 · 패리 · 대시가 끝났을 때, 착지했을 때, 붕괴 고정이 풀렸을 때 ↓ 가 눌려 있으면 곧장 다시 가드다.
   - 스펙: "누르고 있는 동안 가드다".
3. **패리는 공중에서도 된다.**
   - 스펙은 가드에만 "땅에서만" 을 적었다.
   - 지금(v0.6.0)도 공중 패리가 된다.
4. **2타는 1타 도중 아무 때나 J 를 누르면 눌러 둔다.**
   - 값(14)은 누를 때가 아니라 **이을 때** 낸다.
   - 1타가 끝나는 틱에 스태미나가 모자라면 잇지 않고 선다.
5. **맞아도 칼질은 안 끊긴다.**
   - 끝까지 커밋이다(스펙 §5.1).
   - 맞으면 끊기던 것은 차지였다.
6. **패리 시도의 공은 패리 행동이 도는 동안(0.333초)만 산다.**
   - 대시의 공이 대시 행동이 도는 동안인 것과 같은 경계다.
   - 옛 경계(`parry_memory_window` 0.5초)는 스펙이 지웠다.
7. **칼질의 시간(선딜 · 판정 · 후딜)은 데이터에 그대로 적는다.**
   - `FighterDataTests` 가 그 시간을 그림의 장과 맞대어 본다. 지금과 같은 방식이다.
   - 장에서 계산해 내지 않는 이유: 기준 파이터(`TestConfigs.Fighter`)의 시간은 그림과 무관한 "기준값" 이라, 계산하면 시간을 세는 테스트가 전부 움직인다.
8. **기준 파이터의 칼은 그림에서 안 뽑은 사각형 하나, `[-90, 90] × [0, 300]` 이다.**
   - 옛 사거리 90 과 가로가 정확히 같고, 보스 키 297 을 덮는다.
   - 그림의 모양을 쓰면 `hitboxes.json` 을 다시 뽑는 날 칼질을 세는 모든 테스트와 골든이 같이 움직인다.
9. **봇은 1타를 누를 때 2타를 이을지 반반으로 정한다.**
   - 새 난수 도메인 `BotCombo = 5` 를 쓴다.
   - `BotCharge = 3` 은 은퇴시키되 번호는 비워 둔다. Det 의 계약이 재사용을 막는다.
10. **옛 변종 아홉의 노트는 다시 쓰지 않는다.**
    - 그 변종들은 3번 PR 이 지운다. 대신 `patterns.json` 에 ⚠ 한 단락을 둔다.
    - `III-쐐기` 의 셋째 대는 32 → **42** 로 올린다.
    - 이유: 가드를 드는 값 15 가 없어지면 붙든 가드가 셋째를 버텨 그 변종의 봉인이 사라지고, `WedgeSealTests` 가 그 봉인을 못박고 있다.

11. **가드 그림은 이 PR 에서 그대로(idle + 색 + 링)다.**
    - `attack2` f1 자세는 4번 PR(연출)이다.
    - 패리 그림(`attack2` f0~f3)은 이 PR 이다. 스펙 §5.3 이 그것을 패리 행동의 정의로 적었고, 0.333초 커밋 동안 서 있는 그림이 없으면 커밋이 안 보인다.
12. **옛 링(공격 섬광 · 가드 링 · 패리 성공 링)은 이 PR 에서 그대로 둔다.** 링을 걷는 것은 4번 PR 이다. 차지 링만은 기술이 없어지므로 여기서 걷는다.

## Global Constraints

**규칙 층**
- 규칙 층은 Godot 을 모른다. `overfit/battle/rules/**` 에 `using Godot;` 이 없다.
- 새 순수 파일은 `tests/Overfit.Rules.Tests/Overfit.Rules.Tests.csproj` 의 링크 목록에 손으로 한 줄 넣는다. 와일드카드는 금지다.

        _slash.Burst(
            (float)_feel.AttackRingFrom,
            (float)_feel.AttackRingTo,
            _feel.FlashSeconds * 2.2,
            heavy ? _heavySlashColor : _slashColor,
            sparks: heavy ? _feel.SparkCount : 0,
            sparkLength: (float)(_feel.SparkLength * 0.5));
    }

    /// <summary>지금 칼질의 시트. 목록이 비었으면(스프라이트가 없는 판) 빈 이름이라 아래 갈래가 전부 시트 없음으로 빠진다.</summary>
    private SwingSheet Sheet => _swings.Length == 0 ? default : _swings[System.Math.Clamp(_swing, 0, _swings.Length - 1)];

    /// <summary>
    /// 이 칼질을 시트의 속도의 몇 배로 돌리나 — 2타는 같은 attack2 시트를 반속(6fps)으로 돈다(설계 §5.1).
    /// 시트의 속도는 <c>.tres</c> 가 알고, 칼질의 속도는 데이터(<c>combo[].fps</c>)가 안다.
    /// </summary>
    private float SpeedFor(SwingSheet sheet)
    {
        double native = _sprite.SpriteFrames?.GetAnimationSpeed(sheet.Anim) ?? 0;
        return native <= 0 ? 1.0f : (float)(sheet.Fps / native);
    }

    /// <summary>시트가 있는가 — 없는 이름으로 Play 하면 엔진이 ERROR 를 찍는다(<see cref="Animate"/> 의 주석).</summary>
    private bool HasSheet(SwingSheet sheet) =>
        _sprite.SpriteFrames is { } frames && !string.IsNullOrEmpty(sheet.Anim) && frames.HasAnimation(sheet.Anim);

    // ← HoldWindup 의 문서 주석(“탭이든 차지든 같은 그림이다” → “1타든 2타든 같은 규칙이다”) 그대로
    private void HoldWindup()
    {
        SwingSheet sheet = Sheet;
        if (!HasSheet(sheet))
        {
            return;
        }

        if (_windupFresh || _sprite.Animation != sheet.Anim)
        {
            _windupFresh = false;
            _sprite.Play(sheet.Anim, SpeedFor(sheet));
            _sprite.SetFrameAndProgress(sheet.StartFrame, 0.0f);
            AlignToGround(sheet.Anim);
        }

        int last = _sprite.SpriteFrames!.GetFrameCount(sheet.Anim) - 1;
        int hold = System.Math.Min(System.Math.Max(sheet.StartFrame, sheet.BladeFrame - 1), last);
        if (_sprite.Frame >= hold)
        {
            _sprite.Frame = hold;
            _sprite.Pause();
        }
    }

    // ← FollowBlade 의 문서 주석 그대로
    private void FollowBlade()
    {
        if (_sprite.Animation != Sheet.Anim)
        {
            ShowBlade(Sheet.BladeFrame + 1);
        }
    }

    // ← ShowBlade 의 문서 주석 그대로
    private void ShowBlade(int frame)
    {
        SwingSheet sheet = Sheet;
        if (!HasSheet(sheet))
        {
            return;
        }

        bool fresh = _sprite.Animation != sheet.Anim;
        _sprite.Play(sheet.Anim, SpeedFor(sheet));
        _sprite.SetFrameAndProgress(
            System.Math.Min(frame, _sprite.SpriteFrames!.GetFrameCount(sheet.Anim) - 1), 0.0f);
        if (fresh)
        {
            AlignToGround(sheet.Anim);
        }
    }

`ParryAt` 를 둘로 나눈다. 문서의 둘째 문단(판정 틱을 손으로 안 적는 이유)은 `OneAt` 위로 옮긴다.

```csharp
    /// <summary>패리 가능한 판정 하나를 <paramref name="pressAt"/> 틱에 K 로 받아 본다. 관측과 <b>판정이 선 틱</b>을 돌려준다.</summary>
    private static (DodgeEvent Event, int Tick) ParryAt(int? pressAt) =>
        OneAt(i => new InputFrame(0, false, false, Parry: i == pressAt, false));

    /// <summary>같은 판정을 <paramref name="from"/> 틱부터 ↓ 를 붙들어 가드로 받아 본다 (설계 §5.2).</summary>
    private static (DodgeEvent Event, int Tick) GuardFrom(int from) =>
        OneAt(i => new InputFrame(0, false, false, false, false, GuardHeld: i >= from));

    // ← ParryAt 문서의 둘째 문단(판정 틱을 손으로 안 적는 이유)
    private static (DodgeEvent Event, int Tick) OneAt(Func<int, InputFrame> input)
    {
        var sim = OnePattern(OneHit(
            distance: new double[] { 0, 2000 },
            height: new double[] { 0, 300 },
            parryable: true,
            at: 24 * BattleSim.Dt));

        for (int i = 1; i <= 30 && sim.Events.Count == 0; i++)
        {
            sim.Tick(input(i));
        }

        return (sim.Events.Single(), sim.Ticks);
    }
```

`패리_가드_무반응이_서로_다른_관측이_된다`:
- `(DodgeEvent guarded, _) = ParryAt(early, hold: true);` → `(DodgeEvent guarded, _) = GuardFrom(early);`
- 주석 “일찍 눌러 붙들고 있었다” → “일찍부터 ↓ 를 붙들고 있었다”.

```csharp
    /// <summary>
    /// 새 행동을 고른다. 커밋된 행동(대시 · 칼질 · 패리) 중이거나 굳었으면 입력을 버린다 — 칼질 중의 공격만은
    /// 다음 칼로 기억한다. 가드는 커밋이 아니라 <b>자세</b>라, 그 위에서 바로 다른 행동을 고른다(설계 §5.2).
    /// </summary>
    private void Begin(InputFrame input)
    {
        // 칼질 중에 또 누르면 다음 칼을 **기억만** 한다 (설계 §5.1). 1타는 끝까지 커밋이고, 이어지는 것은 1타가
        // 끝나는 틱이다(Chain). 다른 입력은 버린다 — 끝까지 커밋이다.
        if (Action == FighterAction.Attack)
        {
            if (input.Attack && _step + 1 < _config.Combo.Count)
            {
                _comboQueued = true;
            }

            return;
        }

        if (Action is not (FighterAction.Idle or FighterAction.Guard) || Locked)
        {
            return;
        }

        FighterAction pressed = input.Dash ? FighterAction.Dash
            : input.Parry ? FighterAction.Parry
            : input.Attack ? FighterAction.Attack
            : FighterAction.Idle;

        // 못 하는 행동은 안 누른 것과 같다(스태미나 · 공중 대시 한 번). 누른 것이 없으면 남는 것은 ↓ 하나다 —
        // 누르고 있고 땅이면 가드, 아니면 선다 (설계 §5.2: 누르고 있는 동안 · 땅에서만).
        FighterAction wanted = pressed != FighterAction.Idle && CanStart(pressed) ? pressed
            : input.GuardHeld && Grounded ? FighterAction.Guard
            : FighterAction.Idle;

        if (wanted == Action)
        {
            return;
        }

        Spend(Cost(wanted));
        Action = wanted;
        ActionElapsed = 0;
        _step = 0;
        _comboQueued = false;

        if (wanted == FighterAction.Dash && !Grounded)
        {
            _airDashUsed = true;
        }
    }

    /// <summary>
    /// 이 행동을 지금 시작할 수 있나 — 스태미나가 되고, 대시면 공중 대시가 남아 있나.
    /// 공중 대시는 착지하거나 패리를 성공할 때까지 한 번뿐이다 (나인 솔즈) — 몸 충돌이 없어져 공중이 안전지대가 됐으므로,
    /// 무제한 공중 대시는 "공중에 떠서 계속 무적" 이라는 답 하나로 모든 패턴을 지운다.
    /// </summary>
    private bool CanStart(FighterAction action) =>
        Stamina >= Cost(action) && !(action == FighterAction.Dash && !Grounded && _airDashUsed);
```
