# 게임 안의 고르기 — 패턴을 고르는 망 4번 PR 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2단계의 고르기를 망(`network`)으로 바꾸되, 시도마다 반반의 동전으로 무작위 갈래(대조군)를 남긴다. 망은 좁힌 명부(겨냥 1 ~ 2 + 숨통)를
세우고, 근거가 얇거나 도드라진 칸이 없으면 다섯 전부 — 그때는 `uniform` 과 비트까지 같다. 시도마다 디스크에 한 줄을 남겨 판을 되살린다.

**Architecture:**
- 규칙 층(순수 · 테스트가 링크한다): `PlayerNet`(network.json → 로짓 · 골든 순서) · `NetworkPicker`(좁힌 명부 · `PickDecision`) · `StageRoster.Setup`
  의 동전(`Det` 10 `picker_arm`) · `AttemptRecord.Arm` · `RunHistory.Run` · `BattleSim.Drawn` · `AttemptLog`(JSONL 한 줄을 짓고 읽는다).
- Godot 쪽: `Balance` 가 부팅 때 network.json 을 읽는다(`[net][I] loaded` · 오래된 망 `[W]`) · `Battle` 이 동전의 갈래를 로그와 기록에 싣고
  `user://attempts/<세션 시드>.jsonl` 에 한 줄을 덧붙인다(`AttemptFile`) · `BattleDemo` 가 `--history` · `--attempt` 로 되살린다.

**Tech Stack:** C# 12 (.NET 8) · xunit v3 + Shouldly · Godot 4.7.2 · bash

**Spec:** `docs/superpowers/specs/2026-09-28-패턴-고르는-망-design.md` — §6 전부 · §8 · §9 의 4번 줄 · §10 의 4번 줄.

## Global Constraints

- 결정 경로는 사칙연산과 비교뿐 — `Math.Exp` · `Math.Log` · 병렬 · `Vector<T>` 없음(스펙 §8). 로짓의 순서는 골든 그대로다: 표준화 → 층마다
  `acc = b[j]` 에서 입력 순서대로 `acc += w[j][i] * z[i]` → 마지막 층을 빼고 `acc > 0 ? acc : 0.0`.
- 다섯 전부일 때의 뽑기 = `Det.RollInt(시드, PatternPick, 5, k1: draw)` — `UniformPicker` 와 비트까지 같다. 좁힌 명부는 명부 순서.
- 동전 = `Det.RollInt(시도 시드, PickerArm, 100) < network_share_percent` — 뽑기(`PatternPick`)와 다른 스트림이다.
- 1단계는 `uniform` 그대로 — 리플레이 골든(1단계)이 안 움직인다. 링크된 규칙 파일을 바꾼 커밋마다 "안 움직였다" 블록.
- 망이 없는데 단계가 `network` 를 부르면 `[E]` 를 남기고 판을 안 세운다(던지지 않는다 — `StageRoster.Setup` 의 약속).
- 로그의 수는 `F3`(스펙 §6.6).

## Review Focus

1. **다섯 전부 == uniform** — 망 갈래의 `thin` · `no_habit` 시도가 무작위 갈래와 같은 순서를 낸다(테스트).
2. **명부 밖 칸을 안 낸다** — 좁힌 명부의 칸은 명부의 인덱스다(#59 3/6).
3. **heads == 2단계 명부** — 망의 머리가 명부와 다르면 세울 때 거절한다(`[E]`) · 데이터 테스트가 지금의 파일을 본다.
4. **동전이 뽑기를 안 민다** — 무작위 갈래의 뽑기가 `UniformPicker(시드)` 와 같다.
5. **되살리기** — 기록과 시드로 고르기가 다시 선다(상태 없는 조회). 망의 sha256 이 다르면 `[W]`.
