# 조각 8 — 관문과 릴리즈 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Q 표 대조군 · 비교 관문 · 페이즈 GIF · README · v0.12.0.

**Architecture:** Q 표는 순수 규칙 층(`QTable` · `QTableController`)과 공장 콘솔의 `--qtrain`(C# 만 · 판은 `RolloutRun.Play`). 관문은 파이썬(`ml/rl/gate.py`)이
일꾼(`--controller=qtable|forms`)을 보스마다 돌려 표를 낸다. GIF 는 빈 계획 대본 + 시작 체력.

**Tech Stack:** C# (.NET 8) · Godot 4.7 · numpy · ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-01-조각8-관문과-릴리즈-design.md`

## Global Constraints

- 결정론: 난수는 `Det` 만 · 새 도메인 없이 `BossControl` 의 k2 갈래.
- 새 순수 파일은 테스트 · 공장 csproj 두 곳에 링크 · `.uid` 는 `tools/build.sh import`.
- 리플레이 골든(`tools/replay_golden.txt`)은 안 움직인다.
- README 한국어는 합니다체 · 지시어 없이.

## Review Focus

1. 표에 없는 칸 · 열린 칸이 하나인 결정 — 고르기가 가려진 칸을 안 낸다.
2. Q 학습이 스레드 수와 무관하게 같은 표다(판 순서로 고친다).
3. 관문의 시험 묶음이 evalboss 와 같다(같은 파이터 넷 · 같은 시드).
4. 빈 계획 대본의 GIF 가 다음 전투에 시작 체력을 남기지 않는다.
5. 게임의 보스(`forms`) 열이 게임과 같은 조종기다.

### Task 1: Q 표 (규칙 층)
- `overfit/battle/rules/QTable.cs`: `Key(double[] obs, int roster)` · `Pick(key, mask, seed, number, epsilon)` · `Learn(steps, gamma, decideTicks, alpha)` · JSON 읽기/쓰기.
- `overfit/battle/rules/QTableController.cs`: 관측을 받아 고르고 `NetStep` 을 적는다(일꾼이 경험을 쓴다).
- `BossObservation.FighterOffset` · `MoveOffset`(자를 자리).
- 테스트: `tests/Overfit.Rules.Tests/Battle/QTableTests.cs` — spec §5 의 Q 표 항목.

### Task 2: 학습 (`--qtrain` · `tools/build.sh qtrain --name=sp-1`)
- `tools/factory/QTrainProgram.cs` — 바퀴마다 판 256 을 얼린 표로 병렬 · 판 순서로 `Learn` · `metrics.csv`(바퀴 · 승률 · 칸 수 · ε) · `qtable.json`.
- `train.json` 의 `qtable` 절(iterations 200 · episodes 256 · alpha 0.1 · epsilon 0.3→0.05 · seed).
- 학습을 돌려 `out/qtable/sp-1/qtable.json`.

### Task 3: 관문 (`tools/build.sh gate --name=sp-1`)
- 일꾼: `RolloutController.QTable`(`--weights=<표>`) · `Forms`(`--weights=a,b,c`).
- `ml/rl/gate.py`: 일곱 보스 × 시험 묶음 512 판 · `judge(rows)` · `ml/rl/gate/sp-1.json` · 표를 찍는다. 테스트 `ml/rl/test_gate.py`.
- 돌려서 결과를 커밋.

### Task 4: 페이즈 GIF
- `Game.SetNextStart(int)` · `SceneDriver.NewBattle` 이 빈 대본이면 그것을 부른다 · `GifRunner` 에 `net1` · `net2` · `net3`.
- `tools/build.sh gifs net1 net2 net3` 로 찍고 프레임을 눈으로 본다.
