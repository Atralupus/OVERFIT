# 조각 5 — PPO 학습 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 넘파이 PPO 학습기로 보스 정책망을 학습하고, 규칙 · 무작위 조종기보다 판 평균 보상이 높은지 처음 본다.

**Spec:** `docs/superpowers/specs/2026-10-01-조각5-PPO-학습-design.md`

## Global Constraints
- 파이썬은 `ml/.venv`(numpy). 학습 출력은 `out/train/`(커밋 안 함).
- C# 쪽 바뀌는 것은 일꾼의 `--controller` 뿐 — 골든 그대로.
- `tools/build.sh check` 초록 · 파이썬 테스트 초록.

## Review Focus
- PPO 기울기 부호 · 마스크 밖 칸의 기울기 0 · clip 영역.
- GAE 가 판 경계에서 새지 않음.
- 넘파이 순전파와 C# 의 차이(층 순서 · ReLU · w 의 [출력][입력]).
- 바퀴의 시드가 겹쳐 같은 판만 배우지 않음.
- 비교의 시드가 학습의 시드와 겹치지 않음.

### Task 1: 일꾼의 조종기 선택
- `RolloutRun.Play(…, controller)` · `--controller=net|rule|random` · 테스트(규칙 · 무작위 판 · 줄 0).

### Task 2: 넘파이 망 · PPO · GAE
- `ml/rl/net.py`(MLP · 저장 · 읽기) · `ml/rl/ppo.py`(GAE · 손실 · 기울기 · Adam) · `ml/rl/test_net.py`(수치 미분 · GAE · C# 일치).

### Task 3: 학습 고리 · 비교 · 첫 학습
- `ml/rl/train.py` · `ml/rl/compare.py` · `tools/build.sh train` · `ml/rl/train.json` 의 `ppo`. 첫 학습을 돌려 지표와 비교를 PR 에.
