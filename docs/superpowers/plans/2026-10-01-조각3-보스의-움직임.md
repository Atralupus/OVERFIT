# 조각 3 — 보스의 움직임 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 결정의 목록에 물러서기 · 넘어 뛰기 · 뒤로 뛰기를 더한다 — 규칙 조종기는 그대로(0.11).

**Architecture:** 움직임은 판의 상태(`BossTravel` — 물러서기 · 점프)이고 동작이 아니다. `LeapMotion` 에 착지의 쪽(`land`)을 더해 점프 공격은 그대로 두고, `retreat` 움직임을 등록표에 더한다. 칸 배치가 바뀐다.

**Spec:** `docs/superpowers/specs/2026-10-01-조각3-보스의-움직임-design.md`

## Global Constraints
- 리플레이 골든 · 기존 테스트 그대로(칸 상수를 이름으로 쓰는 테스트는 값이 바뀌어도 이름 그대로 통과해야 한다).
- 수치는 `bosses.json` 의 `movement`. 새 순수 파일은 두 csproj 에 링크하고 `.uid` 를 같이 커밋. `tools/build.sh check` 초록.

## Review Focus
- 닿은 틱의 물러서기 재귀(아레나 끝) — 마스크가 막는가.
- 공중의 점프 중 탈진 · 전환 · 반응 — 떠 있는 채 굳지 않는가, 반응이 공중에서 돌진을 세우지 않는가.
- 넘어 뛰기의 착지가 아레나 밖 — 자르는가.
- 점프 중 파이터의 칼 — 몸통이 올라가 발이 높으면 안 닿는가(점프 공격과 같은 몸통).
- 칸 배치가 바뀌어 `Continue` · `FirstMove` 값이 움직인다 — 하드코딩된 숫자가 없는가.

### Task 1: 데이터 · 도약의 착지 쪽 · 물러서기 움직임
- 테스트(`BossMotionTests` 또는 새 `TravelMotionTests`): `LeapMotion` 의 `land: far` 는 파이터 너머 몸 간격 · `away` 는 600 자기 쪽 · 자른다 · `near` 는 지금과 같다. `retreat` 는 틱마다 840/60 멀어지고 보는 쪽 0(그대로) · 끝에서 Finished.
- 구현: `MotionDef.Land` · `Distance` · `RetreatMotion` · 등록표 `retreat` · `BossConfig.Movement`(`MovementDef`) · `bosses.json` · `TestConfigs`.

### Task 2: 판의 움직임 · 칸
- 테스트(`TravelBattleTests`): 스펙 §5 의 판 위 항목들 · `ScriptActions` 단위.
- 구현: `BossActions` 칸 배치 · 이름(`retreat` · `leap_over` · `leap_back`) · `BossTravel`(물러서기 · 점프의 상태 · 웅크림 · 공중 · `Motion`) · `BattleSim` 의 마스크 · 실행 · `AdvanceBoss` 의 걸음 · 착지 = 자유로워짐 · 탈진/전환의 `_fall` · 반응은 점프 중 안 끊음 · `ScriptActions`.
