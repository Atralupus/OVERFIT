# 조각 3 — 보스의 움직임: 물러서기 · 점프 이동

**상태:** 설계 (2026-10-01) · 이슈 #152 · 우산 #149
**잇는 설계:** `2026-10-01-강화학습-보스-design.md`(우산) §3.3 · §9 의 조각 3, `2026-10-01-조각2-결정-지점과-조종기-design.md`(결정 지점 · 칸 · 마스크).
우산 §11 에서 조각 3 이 정할 것(점프 이동의 착지 자리 · 높이 · 몸통 · 연출)을 여기서 정한다.

## 0. 무엇을 더하나

결정의 목록에 움직임 셋을 더한다. 유저가 고른 B — "다가가기 · 물러서기 · 기다리기 · 점프 이동".

```
[기다리기, 다가가기, 물러서기, 넘어 뛰기, 뒤로 뛰기, 계속하기, 동작 0 … 동작 N−1]
```

| 칸 | 무엇 | 그림 |
|---|---|---|
| **물러서기** | 파이터를 본 채 뒤로 달린다 — `retreat_speed`(840 · 달리기와 같다). 결정 간격(12틱)마다 다시 묻고, 아레나 끝에 닿으면 그 틱에 묻는다 | run 을 거꾸로 |
| **넘어 뛰기** | 웅크렸다(0.25초) 파이터 **너머** 몸 간격(반폭 + 반폭) 자리로 뛴다(높이 280 · 0.6초) — 등 뒤를 잡는 사람의 반대편으로 넘어간다 | jump f0 → jump f1 → fall |
| **뒤로 뛰기** | 웅크렸다 파이터에게서 **600** 떨어진 자기 쪽 자리로 뛴다(아레나 안으로 자름) · 파이터를 본 채 | 같다 |

- 점프는 **공격이 아니다** — 판정이 없고 착지에 충격파도 없다. 뛰는 동안 보스 몸통이 같이 올라간다(파이터 칼이 발이 높으면 안 닿는다 · 점프 공격과 같다).
- 점프는 동작(`patterns.json`)이 아니라 판의 움직임이다 — 동작의 규칙(판정 하나 이상 · 착지에 판정)과 안 맞고, 명부에 넣으면 규칙 조종기의 무작위 고르기가
  바뀐다(0.11 이 깨진다). 수치는 `bosses.json` 의 `movement` 다.
- 점프가 끝나면(착지) 그 틱이 **자유로워짐**이다 — 쉬기를 새로 센다. 물러서기는 다가가기와 같이 결정 간격마다 · 끝에 닿으면 `Arrived`.
- **마스크:** 쉬기 · 다가가는 중 · 물러서는 중은 셋 다 열린다. 닿은 틱(`Arrived`)은 다가가기와 물러서기를 가린다(같은 틱에 또 닿아 끝없이 되묻는다 —
  조각 2 의 최종 리뷰). 캔슬 지점에서는 움직임을 안 연다(끊고 잇는 것은 동작뿐).
- **탈진 · 전환 · 반응**이 끼면 움직임이 끝난다. 공중이면 높이만 따라 내린다(점프 공격이 무너질 때와 같다). 폭탄 반응은 뛰는 동안 끊지 않는다 — 공중에서
  돌진을 세우면 떠서 달린다.
- 규칙 조종기는 셋을 안 고른다 — 0.11 그대로다(골든 · 테스트 그대로).

## 1. 데이터

```jsonc
// bosses.json 의 "그림"
"movement": { "retreat_speed": 840, "leap_crouch_seconds": 0.25, "leap_height": 280, "leap_air_seconds": 0.6, "leap_back_distance": 600 }
```

## 2. 움직임의 착지 자리

도약(`LeapMotion`)에 착지의 쪽을 더한다 — `land`: `near`(지금 · 파이터 앞 몸 간격 · 점프 공격) · `far`(파이터 너머 몸 간격) · `away`(파이터에게서
`distance` 만큼 자기 쪽). 기본은 `near` 라 점프 공격이 안 바뀐다. `away` 는 보는 쪽을 안 바꾼다(파이터를 본 채 뒤로 뛴다).

## 3. 뷰

- 물러서기: run 을 거꾸로(속도 음수).
- 점프: 웅크림 jump f0 · 오르는 동안 jump f1 · 내리는 동안 fall.

## 4. 대본 조종기 — GIF 용

`ScriptActions` — 결정마다 칸 이름을 차례로 낸다(`wait` · `retreat` · `leap_over` · 동작 id …). 자유로워짐은 기다리기 · 캔슬 지점은 계속하기 · 다 쓰면 기다리기.
열리지 않은 칸이면 판이 `[E]` 다. GIF · 스크린샷 대본이 쓴다(게임의 단계에는 안 쓴다).

## 5. 테스트

- 물러서기: 결정 간격마다 묻고 그 사이 840 px/s 로 멀어지며 파이터를 본다 · 끝에 닿으면 `Arrived` 이고 다가가기 · 물러서기가 가려진다.
- 넘어 뛰기: 웅크림 15틱 · 공중 36틱 · 파이터 너머 몸 간격에 내린다 · 착지 틱이 자유로워짐 · 판정 없음.
- 뒤로 뛰기: 파이터에게서 600(자른 자리) · 보는 쪽 그대로.
- 공중에서 탈진 · 전환: 높이만 따라 내린다.
- 규칙 조종기 0.11 그대로: 골든 · 전 테스트.
- 무작위 조종기 한 판을 `[E]` 없이.

## 6. 하지 않는 것

- 움직임을 캔슬 지점에서 잇기 · 움직임 중 공격.
- 새 그림.
